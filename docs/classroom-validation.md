# UAIS 小班课堂版验收记录

验收日期：2026-10-26。范围为一位教师、30 个合成学生账号、两个数学课时；使用本机隔离 Postgres 和编译后的 Next.js 应用。没有导入真实学生、调用 AI 提供方、修改远程数据库或部署生产。

本轮本地验收已通过：完整确定性测试、隔离数据库测试、最终编译版的师生完整流程，以及真实经过 90 分钟的持续读取检查均完成。最终功能演练编号为 `mvp34k5p`；90 分钟演练编号为 `mvozw2mq`，两份摘要分别保存。

## 已交付的课堂流程

| 计划要求 | 实现与检查依据 |
| --- | --- |
| 从空白课程建立两课时 | 教师网页创建课程及班级；多选导入两份实际 JSON，校订、预览、事务发布。另支持空白课时及已保存教学草稿导入。 |
| 内容、任务与版本一致 | 课时身份稳定，发布版本不可变；任务引用具体课时版本；V2 发布后，V1 任务仍读取 V1。 |
| 教师真实状态与人数 | 课时卡片按保存修订与最近发布记录显示待发布草稿、目标班级及任务数。评阅页按该任务的已批准有效学生汇总，人数不随分页或筛选改变；草稿/提交总数与修订/反馈指标的重叠含义明确说明。 |
| 独立教师指南 | 学生响应按白名单生成；教师参考答案不进入学生材料。课时包原始 JSON 含教师答案，只供教师导入。 |
| 网页名单与首次设密 | CSV 预览、创建学生账号、仅在本次响应提供初始凭据、15 分钟受限设密会话、本人设密后申请入班及教师审批。已有账号不重置密码。 |
| 文字与图片作业 | 每版最多 3 张 PNG/JPEG、每张 1 MiB；解码、清除元数据、私有存储；上传、删除、提交共享修订检查。图片仅本人及获授权教师可读。 |
| 提交及反馈保留 | 60 份封存提交及 60 张图片按成功回执逐项对账；两个浏览器学生收到教师已发布反馈，退出重登及刷新后读回。 |
| 失败恢复与冲突 | 离线图片经 IndexedDB 暂存、刷新、恢复后恰好一次上传；未确认上传阻止提交；响应丢失复用幂等键；批量图片中断恢复和外部修订冲突另有聚焦测试。 |
| 无 AI 时课堂可继续 | 两课任务默认禁用 AI；全部学习、讨论、提交及手工反馈演练未请求 AI。只读文字的 AI 反馈不声称已识别作业图片。 |
| 持续聊天与完整记录 | 历史读取默认每分钟 30 次、每日 10,000 次；虚拟时钟覆盖 120 分钟。隔离 Postgres 测试验证 600 条消息保留，实时窗口仍为 500 条；归档、分页与完整导出使用一致的访问及隐藏规则。 |
| 课程结束后的保留 | 课程负责人结束课程后保留 180 天；到期先预览再确认清理；清理与并发写入互斥。测试覆盖边界及跨课程隔离。此能力要求 Postgres，外部或本地 JSON 后端拒绝执行。 |

基础演练使用教师及两个不同组学生的真实 Chromium 会话，并用已认证 HTTP 客户端覆盖另外 28 个学生及 30 人同时入班、保存、上传和提交。没有直接往数据库植入课时、成员、学生账号、提交或反馈来跳过网页/API 流程。数据库读取只用于隔离检查及对账。

90 分钟检查是 **30 个已认证客户端每 2.5 秒一轮读取小组聊天历史**，另保留两个浏览器会话。它不是 30 个浏览器持续交互或 90 分钟连续写入压测。每次读取均须成功；`extendedSoak.verified` 只有在完整时长及运行错误检查通过后才为 `true`。

持续检查运行期间补齐了教师课时摘要和提交人数的读取与显示，共涉及六个教师侧类型/查询/界面源文件。持续检查结束后已重新构建，并用最终功能演练验证这些变更；聊天与提交写入实现未变，已用源文件指纹核对。两次运行有不同的编译产物，不能将它们描述为同一次构建完成全部检查。最终短流程的 `extendedSoak.verified: false` 表示该次未重复 90 分钟；完整持续检查结果见独立归档摘要。

性能目标为普通保存、提交及聊天请求 p95 ≤ 2 秒。图片上传独立记录；没有 AI 响应性能结果。所有延迟均是本机隔离环境结果，不代表校园网络或生产服务性能。

## 上线边界

代码、迁移及材料是本地候选实现。生产迁移、部署、真实名单导入和正式师生小班试用仍是独立步骤。本地验收不代表教师或学生已接受系统，也不证明教学效果。

增量迁移 `0013`–`0016` 已在全新隔离数据库验证。本地验收阶段未提交、推送或部署；测试启动的应用与数据库进程均已停止，验收证据保留。后续 Git 提交和 PR 不代表生产迁移或部署。

既有 lint 警告位于 `header.tsx` 的内部导航和 `teaching-unit-draft-media-editor.tsx` 的 `<img>`；既有构建警告位于 `teaching-gradebook-provider-operations.ts` 的动态文件追踪。未把这些无关警告当作本次课堂功能的新故障，也未据此扩大修改范围。

服务器应用记录的清理不等于数据库备份同步永久删除；生产备份保存期及恢复后再次清理尚需按实际部署核实。已导出到用户设备的副本也不受服务器清理控制。
