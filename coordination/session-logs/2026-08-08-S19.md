### Tier placement rationale

- The two data directories are **not** `active-production`. Every production
  runtime path for this data asserts external storage and answers 503 for local
  JSON persistence (`assertTeachingCourseManagementLocalJsonRuntimeAllowed`,
  `assertLearningChatroomTranscriptLocalJsonRuntimeAllowed`), so they apply only
  to development, tests, and non-production lanes. This also matches the already
  quarantined production counterpart `UAIS_TEACHING_COURSE_MANAGEMENT_BACKEND`
  and the sibling `UAIS_EXTERNAL_STORAGE_DATA_DIR`. Independently,
  `tests/env-surface.test.ts` caps `active-production` at 21 names and the tier
  already holds exactly 21, so promotion was not available without an owner
  decision.
- Both were written as explicit catalog entries rather than through
  `createQuarantinedLegacyEntries`, because the shared legacy purpose string
  ("retained for historical release gates or future enterprise modules") would
  have been untruthful for paths current code still reads. Their `owner` is
  `S19/S12` (S12 owns the `src/lib/server/` stores that read them) rather than
  the `S19/S22` the legacy helper would have derived from the name.
- The four reserved names are `optional-live-ai` per plan D6/D9. Their purposes
  are prefixed "Reserved" so nobody reads the catalog as proof the guard or flag
  is enforced today; the wording can be tightened to match the other
  `UAIS_LEARNING_CHATROOM_RATE_LIMIT_*` entries once S12's code lands.
- No new secrets. All six are `serverOnly: true`; no `NEXT_PUBLIC_*` name added.
