# S22 Production Reliability Handoff - UAIS Learning AI Guide

## Objective

Resolve the live `www.uais.top/learning` failure that surfaced as
`智能服务暂时不可用，已保留你的问题。`, provision the owner-approved Neon
Launch database, and verify the real multi-agent provider path in Production.

## What changed

- Provisioned the dedicated Vercel Marketplace resource `uais-neon-postgres`
  under the existing Neon Launch installation in `sin1` (Singapore), with Neon
  Auth disabled and Production/Preview connectivity enabled.
- Set Production `UAIS_LANGGRAPH_PERSISTENCE_BACKEND=postgres`.
- Added official LangGraph PostgreSQL checkpointer/store persistence in the
  isolated `uais_langgraph` schema and extended the migration runner to apply it.
- Reused one controlled published-demo-course access predicate for playback and
  the Production Phoebe learning AI guide instead of querying the unavailable
  ordinary external course database first.
- Bounded each multi-agent provider output to 256 tokens and disabled DeepSeek
  and Qwen thinking only for the three-node multi-agent short-answer path. This
  reduced the live browser request from a failed long connection to a completed
  26.29-second response while preserving the LangGraph topology.
- Deployed from a clean temporary release slice without staging, committing,
  branching, or pushing the dirty root checkout.
