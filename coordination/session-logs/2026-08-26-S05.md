## Implemented

- Each teacher course-settings card now exposes an independently labelled,
  collapsible collaborator region and does not fetch until the teacher opens
  it.
- The panel renders only the safe API grant projection: abbreviated registered
  user id, bounded role/scopes, lifecycle state, and no submitted email
  address.
- Grant controls enforce the selected role ceiling, at least one delegated
  scope, and an optional future expiry before issuing a mutation.
- Grant and revoke requests carry client-generated idempotency keys. A network-
  uncertain retry preserves the same key while the form/action identity is
  unchanged.
- Success is announced only after a separate GET returns the persisted active
  or revoked record. Missing or malformed readback leaves a localized failure
  notice rather than claiming success.
- Revocation requires inline confirmation; all controls have at least a
  44-pixel target and keyboard-visible focus styles.
- Simplified Chinese and English labels, states, instructions, and safe error
  messages were added as one paired copy change. Raw server reason codes,
  exception details, and submitted email addresses are never rendered.
