## Assignment

Owner reported two chatroom UI defects and asked for confirmation + multi-agent fix (Fable 5 decision maker, Opus 5 implementation engineers):

1. The chat area is too small.
2. AI messages appear in a strange/wrong ("opposite") direction.

## Decision-maker verdict

Both complaints confirmed by code inspection and live browser evidence at 1280x720 and 1600x900:

1. Chat column used `min-h-[620px]` with unbounded growth, so the internal `overflow-y-auto` never engaged; the whole page scrolled and the composer sat far below the fold (~2.5 messages visible). The @agents sidebar (4 buttons) consumed ~36% width (`xl:grid-cols-[0.72fr_1.28fr]`).
2. All messages rendered as identical full-width left-anchored cards: no right-alignment for the viewer's own messages, no left-bubble treatment for AI agents (WeChat/iMessage convention), no auto-scroll to newest.

## Changes (files)

- `src/components/pages/learning-page-chatroom.tsx`
  - Grid: `lg:grid-cols-[240px_minmax(0,1fr)]` (full) / `lg:grid-cols-[260px_minmax(0,1fr)]` (embedded), `items-start`; agents panel `lg:grid-cols-1`.
  - Chat column: viewport-bounded `h-[calc(100dvh-360px)] min-h-[360px]` (full) / `h-[560px]` (embedded), `overflow-hidden`; message list `min-h-0 flex-1 overflow-y-auto` so it scrolls internally and the composer stays visible.
